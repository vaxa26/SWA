# Player Server
Managing Players in a Database with simpe HTTP-Request using RestAPI
# Requirements
- Java 22.x
- Gradle 8.8.x
# Tools & Frameworks
Below is a list of Tools and Frameworks that were used.

- Spring
- Spring Hateoas
- Spring Web MVC
- Jackson JSON
- REST API
- Hibernate Validator
- Lombok
- Jakarta Persistence
- SLF4J
- OpenAPI | SwaggerUI
- Docker
- Kubernetes
- PlantUML
